About this template

A clean saffron-themed website starter for GitHub Pages. It is suitable for classes, small organizations, course pages, portfolios, and static blogs.

How it works

Every page contains two placeholders: site-header and site-footer. The JavaScript file fetches the shared HTML files and places them into the page.

Why this is useful

You do not need to copy the navigation and footer into every page. Edit the partial once and the full site changes.

Suggested use

Replace the placeholder images with your own images, update text, change links in partials/header.html, and publish the full folder to GitHub Pages.
